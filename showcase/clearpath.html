Learn medical device project management by doing.

ClearPath QMS is a guided project-management tool for people new to medical device development. It pairs a real project board with an AI coach and in-context learning, so a newcomer can run a device project end-to-end while the tool teaches the "why" — design controls, ISO/IEC standards, risk management, and regulatory submissions — as they go.

The problem it solves

Breaking into medtech PM is hard — the regulated vocabulary is a wall.

A capable project manager moving into medical devices suddenly faces ISO 13485, design controls, ISO 14971 risk management, 510(k) submissions, and traceability — with no guide. ClearPath QMS turns that learning curve into a guided workflow: you build a real project, and the tool explains each regulated concept exactly when you need it.

What it does

A tool you learn through — every screen does double duty.

🎓

Guided onboarding

A welcome flow walks through the 7-phase device lifecycle and scaffolds a starter project to learn from.

💬

AI Coach

Ask plain-language questions ("What's a 510(k)?") and get mentor-style answers grounded in your actual project.

📊

Phase readiness

Gap analysis shows the standard deliverables each phase needs — and what you're still missing.

🔗

Requirements traceability

Link design inputs → outputs → verification, and flag coverage gaps the way auditors do.

📋

Board, timeline & glossary

Manage tasks across all phases, with an in-context glossary that defines the jargon.

🗂️

Audit trail

Every change is recorded append-only with who/what/when — a step toward 21 CFR Part 11 record-keeping.

How it's built

A modern, pragmatic stack — and a thoughtful approach to AI.

React + Vite Node / Express Swappable LLM providers Local AI (Ollama) — zero cost Append-only audit trail Autonomous agent (tool-use)

The AI runs on a free local model by default, with the option to switch to a hosted model for higher quality — demonstrating cost-aware architecture. An optional autonomous agent can review the board and maintain it via an LLM tool-use loop.
